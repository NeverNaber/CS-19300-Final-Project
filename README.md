Java Chess

Project Goal:
I would like to cure boredom by creating a game I can play with friends. I would like to make a  2 player chess game playable on either terminal or in a window.

Build:
I am going to build a 2 player chess game in either terminal or a java window.

Tech Stack:
Language: Java
IDE: Visual Studio Code
Interface: Terminal or Java window (not yet decided)

Milestone Plan:
1. Get the board and pieces to show up visually.
2. Get the logic for pieces moving and where they can go.
3. Disallow pieces moving when they go past an edge, on a same colored piece, etc.
4. Logic for captures and removing pieces.
5. Logic for final conditions like checkmate or stalemate.
6. Misc conditions and rules like castling or not being able to move king in check.

MVP / Eisenhower:
Do - (Your MVP):
Board
Captures
Piece moving logic

Schedule - (For V2.0+):
Misc conditions
Misc rules
All types of wins and draws

Delegate - (Use a library):
Visual of board
Visual of pieces
Save and load unfinished games

Delete - (Cut it):
Proper notation
Online usage
Single player against AI
